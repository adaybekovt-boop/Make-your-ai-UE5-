## Что реализовано

Один владелец состояния компании и один таймер; int64-микродоллары с сохраняемыми остатками начисления; детерминированные сохраняемые RNG; реальные описания девяти существующих площадок и настраиваемого Greenhaven. Нет выдуманного последовательного открытия домашних площадок.

Garage: выбор и покупка → ячейка → выбор шасси/чипа/канала/количества → атомарная оплата → ETA → пауза → доставка на склад → ручной монтаж/апгрейд → обновление сетки → сохранение и восстановление состояния. Успех этого потока подтверждён для переносимого домена и сравнения с TypeScript. Полный поток через UMG, диск USaveGame и перезапуск Editor ещё не проверен.

Есть настоящий UMG WidgetTree: панель компании/времени, статусы локаций, закупка, установка, склад, заказы, уведомления, сохранение/загрузка, аукцион и регионы/энергия. Бизнес-кнопки связаны с C++-операциями.

Auction имеет конкурента, бюджет, эскроу, возврат при перебитой ставке и выдачу выигрыша обычными заказами без второго списания. АЭС единственная на компанию, не занимает ячейку, меняет только тариф, не создаёт выручку. Greenhaven использует общие регионы и общий судебный риск. Для этих новых систем отсутствует утверждённый баланс: производственные configured-флаги выключены, цены из тестов не включены в игру.

NPC: один демонстрационный персонаж с Idle/PhoneCall/React, входом в радиус, cooldown, сохранением и делегатом для будущей анимации/звука. Это не crowd simulation.

## Ограничения и оставшаяся работа

Экономика вертикали покрывает базовый онлайн-флагман с аудиторией, а не полный порт `src/systems/models`. Обучение, несколько моделей, полный набор контрактов/команды/конкурентов/рекламы/страхования/событий ещё не перенесены. Новых офисов/налогов нет. Ручная партия 1× и стресс-проверка неблагоприятных событий не выполнялись.

Runtime-стойки пока HISM-прокси; подробные импортируемые модели не подключены к их отображению. UMG временный англоязычный, адаптивность и доступность не проверены. Сохранения UE не импортируют IndexedDB; изменение каталога требует явной миграции. Проверки крайних складских/аукционных комбинаций не исчерпывающие. Cook/package, поиск ассетов в packaged game и API-совместимость с конкретной UE-версией не проверены.

Импорт CityV4 пока сохраняет полную композицию в combined reference mesh; это не пространственная разбивка для World Partition. Параметры streaming нужно выбрать и проверить отдельно, а не объявлять готовыми по наличию world setting.
