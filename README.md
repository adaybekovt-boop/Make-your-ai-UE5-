# NEURON — Создай свой ИИ

Одиночная игра об AI-компании на Unreal Engine: начните с гаража, закупайте
серверы, работайте с данными, обучайте модели и развивайте компанию.

## Скачать и запустить

Игра распространяется готовой сборкой для Windows.
Готовые версии размещаются в [GitHub Releases](https://github.com/adaybekovt-boop/Make-your-ai-UE5-/releases).
Если в релизе ещё нет архива Windows, исполняемая сборка ещё не опубликована.

1. Скачайте архив Windows и распакуйте его целиком.
2. Запустите `MakeYourAI.exe`. Не переносите один exe отдельно от остальных файлов.
3. При отсутствии компонентов используйте включённый `vc_redist.x64.exe`
   в папке `Engine/Extras/Redist/en-us`.

Unreal Editor, Blender, Node.js и исходники для игры не требуются.

## Управление картой

- Колесо — приближение к курсору и отдаление.
- ПКМ + движение — перетаскивание карты.
- Средняя кнопка или Shift + ПКМ — вращение и наклон.
- WASD — движение; Home — общий вид.
- ЛКМ — выбор площадок и кнопок интерфейса.

По умолчанию — ограничение 60 FPS. На общем виде отключаются динамические
тени солнца, вдали используются упрощённые LOD и скрывается дальняя
растительность. При приближении возвращаются полная геометрия и тени.

## Системные требования

Нужны 64-разрядная Windows и видеокарта с DirectX 12 / Shader Model 6.
SSD рекомендуется для загрузки города. Размер загрузки указан у архива релиза.

**Минимальная конфигурация пока не подтверждена аппаратными тестами.**
Нельзя получить честный минимум или обещать максимальные настройки на слабой
карте по результатам одного мощного компьютера.

Фактический проверочный стенд: Intel Core i9-12900KF, NVIDIA GeForce RTX 3090
24 ГБ, 64 ГБ RAM. Это не минимальные требования и не рекомендация покупать
такое оборудование. Замеры и ограничения первой версии перечислены в
[отчёте проверки](Unreal/Parity/LOCAL_UE58_STATUS.md).

## Сохранения

Используйте «Сохранить» перед выходом. Игра хранит локальные сохранения компании;
браузерные сохранения автоматически не импортируются.
